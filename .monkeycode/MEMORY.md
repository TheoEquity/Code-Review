# 用户指令记忆

本文件记录了用户的指令、偏好和教导，用于在未来的交互中提供参考。

## 工作环境

- **机器配置**: 8GB 内存，20GB 硬盘（不能扩容）
- **访问方式**: 用户只能通过预览链接访问，无法本地访问
  - 每次启动服务后必须为用户开放预览端口

## 工作流程规范

### 1. 任务开始前
- 每次执行任务时必须先从本 memory 文件中读取用户要求和偏好

### 2. 错误处理
- 测试发现错误后必须先分析原因
- 提出解决方法，经用户批准后方可修改部署
- 不可擅自变更代码
- 仅修改本次错误代码所涉及的范围，严禁修改无关代码

### 3. 系统操作
- 原定系统操作出现问题要先分析原因
- 经用户确认后再进行操作
- 不得自行绕路解决或自行降低标准

### 4. 开发完成后的自检
- 开发完成后自行充分测试
- 检查前端、后端情况及是否需要编译才能生效
- 全部准备工作完成后再通知用户测试

### 5. 信息记录
- 工作中相关系统信息、数据库信息和关键字段、关键方案简要记录在 memory 中供后续阅读
